# KHWAMI

KHWAMI is an AI Engineering Workspace.

## Purpose

KHWAMI provides a documentation-first foundation for reusable AI-assisted
engineering guidance. It organizes engineering standards, AI instructions,
prompt assets, repository intelligence, planning records, and state records so
people and AI agents can find and use the appropriate material consistently.

## Scope

KHWAMI covers the repository's identity, reusable engineering guidance,
prompt-library assets, repository-intelligence documentation, planning records,
and current-state records.

KHWAMI does not define a product application or a deployable runtime system.
Future capabilities and workflows are outside this identity baseline unless they
are established by a separate, explicitly scoped document.

## Core Principles

At a high level, KHWAMI emphasizes:

- clear ownership of information by document and directory,
- maintainable, readable, and reusable engineering guidance,
- evidence-based repository understanding,
- focused context and minimal unnecessary duplication, and
- consistent terminology and repository-relative references.

## Official Terminology

| Term | Usage |
| --- | --- |
| **KHWAMI** | Official name and preferred short reference. |
| **AI Engineering Workspace** | Generic definition and category of KHWAMI. |
| **khwami** | Preferred repository name and lowercase repository identifier. |

## Referencing KHWAMI

KHWAMI is the official name. Other documents should normally refer to the
system as **KHWAMI** without restating its full definition.

The phrase **AI Engineering Workspace** should be used when explaining what the
name means or identifying its category. The complete identity definition is
maintained in this document; other documents should link to or reference
`KHWAMI.md` rather than duplicate it.

## Identity Boundary

This document establishes KHWAMI's naming and identity baseline only. It does
not define project creation, project adoption, execution permissions, or any
other engineering workflow.
